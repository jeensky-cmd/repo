# 설문 집계기

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표(문항 / 유효 응답 / 평균 / 빈 응답 / 제외)를 보여 주는 단일 페이지입니다.

- `index.html` 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 배포하면 됩니다.
- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않습니다.
- 붙여넣은 데이터는 브라우저 밖으로 보내거나 저장하지 않습니다(CSP `default-src 'none'`).

## 집계 규칙

- 첫 줄은 머리글, 첫 열(응답번호)은 집계하지 않습니다.
- 앞뒤 공백을 지운 값이 1·2·3·4·5 중 하나면 유효, 비었거나 공백만 있으면 빈 응답, 그 밖의 값은 제외입니다.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다. 머리글보다 많은 칸은 무시합니다.
- 평균은 유효 응답의 합 ÷ 유효 응답 수를 소수 셋째 자리에서 반올림해 둘째 자리까지 표시하며, 유효 응답이 없으면 `-`입니다.

자세한 설계는 [docs/PLAN.md](docs/PLAN.md)에 있습니다.

## 시험

Node.js 18 이상, 설치할 의존성은 없습니다.

```bash
npm test
```

- `tests/core.test.js`: `index.html`의 `<script id="survey-core">`(계산 로직)만 꺼내 DOM 없이 시험합니다.
- `tests/static.test.js`: 외부 자원·네트워크·저장소 API가 없는지, CSP와 `.nojekyll`을 검사합니다.
