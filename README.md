# 10×10 오목

브라우저에서 바로 하는 10×10 오목입니다. `index.html` 하나로 동작하고, 설치나 서버가 필요 없습니다. 외부 라이브러리·글꼴·분석 도구를 쓰지 않으며 외부로 연결하지 않습니다.

## 하는 법

- `index.html`을 브라우저로 열거나 GitHub Pages로 배포합니다.
- 대전 방식: 두 사람(한 화면에서 번갈아) / 컴퓨터와(나는 흑 또는 백)
- 흑이 먼저 두고, 가로·세로·대각선으로 같은 색 **5개 이상**을 먼저 이으면 이깁니다. 금수는 없습니다.
- 판이 다 차도 승자가 없으면 무승부입니다.
- 무르기: 마지막 수를 되돌립니다. 컴퓨터 대전에서는 컴퓨터 수와 내 수를 함께 되돌립니다.
- 키보드: 방향키로 이동, Enter·Space로 돌 놓기.

설계는 [docs/PLAN.md](docs/PLAN.md)에 있습니다.

## 시험

Node.js 18 이상, 설치할 의존성은 없습니다.

```bash
npm test
```

- `tests/core.test.js`: `index.html`의 `<script id="gomoku-core">`(게임 로직)만 꺼내 화면 없이 시험합니다.
- `tests/static.test.js`: 외부 자원·네트워크 API가 없는지, `.nojekyll`이 있는지 검사합니다.
