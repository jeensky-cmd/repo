# 10×10 오목 계획서

## 목표

브라우저에서 바로 여는 10×10 오목 게임 `index.html` 하나. 설치·서버·외부 라이브러리 없음.

## 규칙

| 항목 | 규칙 |
|---|---|
| 판 | 가로 10 × 세로 10, 교차점에 돌을 둔다 |
| 순서 | 흑이 먼저, 흑·백이 번갈아 한 수씩 |
| 승리 | 가로·세로·대각선으로 같은 색 돌이 **5개 이상** 이어지면 승리(자유 규칙, 장목도 승리) |
| 금수 | 없음(10×10 판이라 렌주 금수 규칙은 넣지 않음) |
| 무승부 | 100칸이 모두 찼는데 승자가 없을 때 |

## 기능

- 대전 방식: **두 사람**(한 화면에서 번갈아) / **컴퓨터와**(사람이 흑 또는 백 선택)
- 무르기: 마지막 수를 되돌린다. 컴퓨터 대전에서는 컴퓨터 수와 내 수를 함께 되돌린다.
- 새 게임
- 마지막 수 표시, 승리 줄 강조, 현재 차례·결과 표시
- 키보드로도 둘 수 있음(방향키로 이동, Enter/Space로 착수)
- 밝은/어두운 화면, 휴대폰 폭

## 컴퓨터 수 고르기

1. 바로 이길 수가 있으면 둔다.
2. 상대가 바로 이길 수가 있으면 막는다.
3. 그 밖에는 빈칸마다 네 방향의 연결 모양(이어진 수, 열린 끝 수)으로 공격 점수와 수비 점수를 매겨 가장 높은 칸을 고른다. 같은 점수면 판 가운데에 가까운 칸.

결정적으로 동작해 시험이 가능하다(무작위 없음).

## 구조

- `index.html`
  - `<script id="gomoku-core">`: 판 상태·착수·승패 판정·무르기·컴퓨터 수. DOM을 참조하지 않는다.
  - `<script id="gomoku-ui">`: 판 그리기, 클릭·키보드 입력.
- `tests/core.test.js`: `index.html`에서 core 블록만 꺼내 Node `vm`으로 시험(`node --test`, 의존성 없음).
- `tests/static.test.js`: 외부 자원·네트워크 API가 없는지, `.nojekyll`이 있는지 검사.
- `.nojekyll`, `.github/workflows/test.yml`(기존 것 유지).
